# Radiative-Transfer-Comparisons-Between-Satellites-and-BGC-Argo-Floats

This repository consists of a workflow that will allow the user to examine differences between remote sensing and in situ measurements of ocean optics. The purpose is to compare diffuse attenuation coefficient values between satellite data and Bio-Argo float data. The bio-optical model, HydroLight, is used to derive diffuse attenuation coefficient and other irradiance properties from chlorophyll concentration profiles. The code here will prepare the files to be entered into HydroLight and then detail the processing of those results to be compared to the satellite data. This workflow can be used to investigate differences between other outputs of HydroLight, other locations and time periods, and other satellites. 
The analysis performed in this study found that in the Southern Ocean when chlorophyll concentration is low, the float and satellite diffuse attenuation coefficients are closer in proximity to each other than when the chlorophyll concentration is high. Chlorophyll concentration and diffuse attenuation coefficient are correlated as chlorophyll absorbs light, contributing to the light attenuation in the water column. Both PACE and VIIRS satellite data was used in this study. The results suggest that the satellite algorithm is not as adept at measuring high diffuse attenuation coefficients as the in situ Bio-Argo floats.
